# Easier Recipes

A Minecraft plugin that makes crafting and recipe management easier.

> **Current supported Minecraft version:** `1.21.11`

## About

Easier Recipes is designed to simplify recipes and crafting in Minecraft. Details about supported features, commands, permissions, and configuration will be added as development progresses.

## Documentation

The [Wiki](../../wiki) is the main place for user documentation, including:

- Installation instructions
- Commands
- Permissions
- Configuration
- Supported recipes and features
- Troubleshooting and frequently asked questions

## Support and bug reports

If you find a bug or would like to request a feature, please [open an issue](../../issues/new/choose). When creating an issue, include:

- The Minecraft version you are using
- The Easier Recipes version
- Your server software and version, such as Paper or Spigot
- Steps to reproduce the problem
- Relevant error messages or logs
- Screenshots or other helpful details

Please search existing issues before creating a new one.

## Compatibility
