# Troubleshooting

## Before opening an issue

1. Confirm that you are using Minecraft `1.21.11`.
2. Confirm that your server software is supported.
3. Check the server console for errors.
4. Check the existing issues for a matching report.
5. Reproduce the problem with only the required plugins when possible.

## Reporting a problem

Use the repository's **Bug report** issue template and include your server software, plugin version, steps to reproduce, and relevant logs.

Never post passwords, tokens, private IP addresses, or other sensitive information in an issue.
