# Installation

## Requirements

- Minecraft `1.21.11`
- A compatible server platform, such as Paper or Spigot
- The Java version required by your server platform

## Steps

1. Download the Easier Recipes plugin file from the official release location.
2. Stop your server.
3. Place the plugin file in the server's `plugins` folder.
4. Start the server.
5. Check the server console for the plugin startup message.

## Updating

1. Stop the server.
2. Replace the old plugin file with the new version.
3. Start the server and check for errors.

> Replace this page with the exact download and compatibility information once releases are available.
